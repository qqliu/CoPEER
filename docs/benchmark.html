Certified-claim localization

Can a critic point to the line that is wrong?

A critic receives the numbered source text and a request for up to three candidate lines, ranked by preference, with a brief explanation. The prompt says that the text contains an error and withholds the dossier's counterexample and certificate. A reference line is one of the input's accepted error lines, backed by a core dossier: Hit@1 counts a reference line as the first choice, Hit@3 a reference line among the first three. Responses that break the response or execution rules count as misses.

Protocol

Inputs, scoring and uncertainty

The primary evaluation uses 100 texts from the human-approved core, each with at least ten nonblank source lines, grouped into 92 problem clusters; a supplementary evaluation adds 31 shorter texts, 131 scorable inputs in all. Every attempt has a 16,000-token output allowance and a 600-second wall limit. A response is scored on its parsed line numbers only: an invalid slot counts as a miss, inputs that exceed the recorded context limit receive a setup refusal and count as misses, and the one-line text baselines have no top-three result. Confidence intervals use 10,000 bootstrap resamples of problem clusters, keeping related texts together.

The score measures reference-line selection on texts known to contain an error. It is not general proof-verification accuracy and not a false-accusation rate; a separate LLM review of saved responses found that some responses that select a reference line do not supply a valid objection, while some that miss it do. Human approval covers every core dossier; exact current line labels were reviewed separately on smaller samples (79 of the 147 core records carry an exact current human review of the line label in the release).

    First-choice misses

    The paper examines a random sample of 30 of Sonnet 5's 58 readable first-choice misses in the earlier 191-input evaluation (seed 20260921), with LLM reviewers classifying each miss; the released records preserve the original classifications, later adjudications and the disagreements. A separate LLM review of 24 paired texts (Experiment B) assessed whether responses supplied a valid objection: Gemini 3.1 Pro had 20 reference matches and 20 of 24 valid objections, Nemotron 3 Super 18 matches and 19 of 24 valid objections, with valid objections among both matches and misses.
