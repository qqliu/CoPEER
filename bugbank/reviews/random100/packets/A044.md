## 4. Exact released witness

~~~~text
Take n = 2. It is an integer and n ≥ 1. The actual sum is ∑_{k=1}^2 k² = 1² + 2² = 1 + 4 = 5. The claimed formula gives 2(2+1)(2+2)/6 = 2·3·4/6 = 4. Since 5 ≠ 4, the universal claim is false.
~~~~
