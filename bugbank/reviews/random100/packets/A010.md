## 4. Exact released witness

~~~~text
Fix x = √2. Choose irrational divisors d₁ = √2 and d₂ = √2/2. Then x/d₁ = 1, while x/d₂ = 2. The divisors are distinct because √2 ≠ 0. Both are irrational: √2 is irrational, and if √2/2 were rational, multiplying it by 2 would make √2 rational.
~~~~
