## 4. Exact released witness

~~~~text
Two finite witnesses.

WITNESS 1 (refutes the verbatim sentence 'it has a least element ⊥, which is contained in every filter'): the two-element Boolean algebra B = P({e0}) = {⊥, ⊤}, with the filter F = {⊤}. F is nonempty, meet-closed (⊤∧⊤ = ⊤ ∈ F) and upward closed (the only y ≥ ⊤ is ⊤ ∈ F), so F is a filter; and ⊥ ∉ F. The claim says ⊥ ∈ F for every filter F; here F = {⊤} is a filter and ⊥ ∉ F.

WITNESS 2 (refutes the related line-39 claim 'if 𝓕 is a proper filter containing a, then 𝓕 is not maximal'): the four-element Boolean algebra B = P({e0,e1}) = {⊥, {e0}, {e1}, ⊤}, the element a = {e0}, and the filter F = {{e0}, ⊤}. F is a filter, a ∈ F, and F ≠ B (⊥ ∉ F, so F is proper). Any filter strictly containing F would contain {e1}, hence ⊥ = {e0} ∧ {e1}, so it would be the whole algebra; thus F is maximal among proper filters (it is the ultrafilter generated by the atom {e0}), contradicting the claim.

The selected Lean theorem certifies both witnesses with Mathlib Order.PFilter: ⊥ ∉ F for F = PFilter.principal true on Bool, ¬∀ G : PFilter Bool, ⊥ ∈ G, and for U = PFilter.principal (true,false) on Bool × Bool: (true,false) ∈ U, ⊥ ∉ U, and every G with ⊥ ∉ G and U ≤ G satisfies G ≤ U.

Remark (elementary, not part of the selected declaration): a filter is nonempty and upward closed, so ⊤ belongs to every filter, whereas ⊥ belongs to a filter only if that filter is the whole algebra; the proof needed the former fact.
~~~~

    (⊥ : Bool × Bool) ∉ U ∧
    ∀ G : PFilter (Bool × Bool), (⊥ : Bool × Bool) ∉ G → U ≤ G → G ≤ U := by
  refine ⟨by change ¬ ((true, false) ≤ (false, false)); decide, ?_⟩

  · exact False.elim (hproper hmeet)

  · simp [U]
