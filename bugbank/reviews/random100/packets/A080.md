## 4. Exact released witness

~~~~text
line with lineality: every face = P

Take A = [[0,1],[0,-1]] and b = [0,0]. Then P = { (u,v) : v <= 0 and -v <= 0 } = { (u,0) : u in R }, a line. Let F = P. Under the proof's face definition, for every subset I of the two inequalities, the set {z in P : a_i^T z = b_i for all i in I} is still P, since both inequalities are tight on all of P. Hence F is a nonempty minimal face. But (0,0) and (1,0) are distinct points in F, so F is not a singleton.
~~~~
