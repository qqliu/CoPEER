P1 | Why 1 is a Mersenne number (explanation)
1 | The following is targeted at people learning math and bitwise operations. It was originally intended to be a proof, but it's not rigorous enough AFAIK, so I decided to make it a learning resource.
2 | 
3 | 1st let's use the standard definition. A Mersenne number (prime or not) is Natural of the form 2^n - 1 for an arbitrary Natural n.
4 | 
5 | If we use the 0-based Naturals, then 0 is allowed, resulting in 2^0 - 1 = 0. The problem with allowing 0 is that it's even, so let's use a stricter definition of M numbers, such that all M numbers must be odd.
6 | 
7 | The number 1 is odd, and so are infinitely many integers that are not in the set of M numbers, so it's not enough to prove that 1 is in the M set.
8 | 
9 | Define the bit-length function as bl(n) = ilb(n) + 1. Where ilb is the integer binary logarithm, defined as ilb(x) = trunc(lb(x)), and lb(x) = ln(x) / ln(2).
10 | 
11 | bl(0) is a controversial special case, some define it as 0, others as 1, others say it's just undefined. We'll use 1 because bl(n) can be defined algorithmically as "the number of bits until the most significant unset-bit is found, with an initial counter set to 1" since the number 0 is represented as "...000" in the positional binary numeral system, the 1st bit is already the most significant bit, so it returns 1 immediately.
12 | 
13 | Define the binary Hamming Weight function as popcount(n) = digit_sum(n, 2) where the 2nd argument specifies the base or radix.
14 | 
15 | Define the Count Trailing Ones function as cto(n) = "the number of consecutive set-bits at the least significant part of the numeral".
16 | 
17 | Lastly, define the bitwise "isM" as `isM(n) := ((n & (n + 1)) ==  0)` . This fn returns a boolean value. The `&` operator is a bitwise AND gate applied to all bits. IIRC, it has been proven that `isM` correctly answers whether n is in M or not, for every n.
18 | 
19 | Since all M numbers are repunits in base 2, the following equation must be true for every n in M: bl(n) = popcount(n) = cto(n) and isM(n) = true.
20 | 
21 | **bl(1) = 1, popcount(1) = 1, cto(1) = 1,** and `(1 & 2) = 0` . Therefore 1 has passed all tests and requirements to be considered a M number. QED.
22 | 
23 | But wait! We haven't tried to find counterarguments:
24 | * A good one is based on the statement "all M numbers must be either prime or composite", **but 1 is neither** because it doesn't belong to any of those sets, so under that definition, 1 is not in M. If we use a *loose* (ambiguous) definition like "all values in M must be prime or not prime" then 1 matches the part "not prime" and we can claim that 1 must be in M because of all the other reasons mentioned previously.
25 | * Citing [this Wikipedia section](https://en.wikipedia.org/wiki/Mersenne_prime#Theorems_about_Mersenne_numbers) "M numbers can never be perfect powers". Under that definition, 1 cannot be in M. But we can tweak the definition to only exclude non-trivial powers. 1 is a trivial power because 1^x = 1 for any x in R, and x^0 = 1 for any x in C. Non-trivial powers can be represented uniquely, but there's infinite ways to write 1 as a power. So we can use the statement "No value in M can be a non-trivial perfect power", 1 fits this definition, and therefore belongs to M.
26 |

## 4. Exact released witness

~~~~text
Over natural numbers, interpret a non-trivial power representation as an ordered pair (a,b) with a>1, b>1, representing a^b. Take 64: 2^6=64, 4^3=64, and 8^2=64. The distinct pairs (2,6), (4,3), and (8,2) all satisfy the non-triviality conditions, so representation is not unique.
~~~~
