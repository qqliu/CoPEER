## 4. Exact released witness

~~~~text
Take n = 0, an integer. Then |2n| = |0| = 0. For every nonnegative integer m, 3^m ≥ 1, so 3^m + 1 ≥ 2. Hence the required lower bound 3^m + 1 ≤ 0 is false. Therefore no admissible m exists.
~~~~
