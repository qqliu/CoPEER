## 4. Exact released witness

~~~~text
p = 3 (the sentence's 'on p edges' is read contextually as p vertices, as in the question's opening line). The bipartite graph K_{1,2} on vertices {0,1,2} with edge set {(0,1),(0,2)} has parts {0} and {1,2} and exactly 2 edges. The claimed greatest number of edges is p²/4 = 9/4, and 2 ≠ 9/4. Moreover 9/4 is not an integer, so no graph on 3 vertices has 9/4 edges at all: whatever the true maximum is, it is a natural number and cannot equal 9/4. The selected Lean theorem certifies exactly these facts: G has edgeFinset.card = 2, every edge joins vertex 0 to a non-zero vertex (bipartite with parts {0} and {1,2}), (2 : ℚ) ≠ 3²/4, and no natural number m has (m : ℚ) = 3²/4.
~~~~
