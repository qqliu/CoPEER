## 4. Exact released witness

~~~~text
Take the integer q = 0. Then 6q + 2 = 6·0 + 2 = 2, while 2(3q + 2) = 2(3·0 + 2) = 4. Thus the asserted equality gives 2 = 4, which is false.
~~~~
