## 4. Exact released witness

~~~~text
Let G=K2,2 on {0,1,2,3}, with edges02,03,12,13. Every vertex has degree2=n/2. Choose the simple path P=0,2,1, which extends to0,2,1,3. Endpoint0 has only neighbor2 among the other path vertices {2,1}, so its on-path neighbor count is1<2=n/2; the same holds for endpoint1. Neither possible crossing-chord index works, because edge01 is absent. The error is that a whole-graph degree lower bound does not transfer to an arbitrary path: endpoint neighbors may lie outside it. A maximum-length path supplies the needed endpoint containment, because an off-path endpoint neighbor would extend that path. No inequality k-1<n/2 is implied or needed; here k-1=n/2=2.
~~~~
