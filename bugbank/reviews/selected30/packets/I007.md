## 4. Supplied witness

Use the source's open neighborhood N(S) = {w : some v in S is adjacent to w}. A three-element set contained in {1,2,3,4} has four neighbors. A three-element set meeting {0,5} has five neighbors, whether it contains one or both vertices of that edge. Thus every set of size n/2 satisfies the assumed lower bound. But N({0}) = {5}, of size 1, so the asserted singleton lower bound 4 fails. The selected Lean theorem proves this six-vertex open-neighborhood witness.
