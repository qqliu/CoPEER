# Proof development with retrieved counterexamples

The 50 paired tasks are evaluated under a shared stopping rule and the original rule, with three models: GPT-5.6 Sol, Gemini 3.1 Pro and Claude Opus 5. The four reported conditions produce 600 selected final drafts. Inputs, grading references, every selected draft and grade, exact prompts, schemas, and native token-component snapshot are included.

Run `python studies/proof_development/replay.py` (Python 3.9+, standard library). It applies the four saved completion grades to the original snapshot, reproduces all six published correctness/token rows and 2,000-resample task-paired ratio intervals, and checks separately reported grading/additional-attempt costs. No solver or grader runs occur.

`snapshot.json` is the proof-only projection of the frozen snapshot; the unrelated Lean experiment is omitted. `studies50_results_20260917.json` contains the exact expected proof results. The original source publisher is retained in `source/`, while `replay.py` is the portable proof-only adaptation using its arithmetic helpers. Unknown native usage remains unknown, and lower-bound token counts stay marked as such.

Retrieval used a 661-entry database snapshot, SQLite FTS5 BM25 and at most three returned records per queried claim. The released protocol and original retriever code describe the query and stopping rules. The exact historical database SHA-256 matches the study manifest. Its 661 entries and FTS5 index rows are provided as `retrieval_snapshot.json`, separate from the current 284-record release. Build the logical index with `python studies/proof_development/build_retrieval_database.py studies/proof_development/retrieval.sqlite`; then query it with `python studies/proof_development/retrieve.py --query "every Eulerian graph is Hamiltonian" -k 3`. The JSON records any text normalization changes and preserves original rowids. Full service sessions are not included. The portable replay reproduces saved results; new stochastic generations require model access. See `prompts.json` and the manuscript's proof-development appendix for execution settings. Machine paths and CLI session identifiers are removed; model identities are retained.
