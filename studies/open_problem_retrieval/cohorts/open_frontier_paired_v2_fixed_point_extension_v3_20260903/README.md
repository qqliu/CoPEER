does not append to or modify the original experiment. `EXTENSION_MANIFEST.json`
binds the final original validation report, its checkpoint commit, the exact
source inputs, and every terminal seed artifact.

Launch is blocked until a separately reviewed runtime seal is installed and
validated. See `PROTOCOL.md` for the three forced search directions and stopping
rules.
