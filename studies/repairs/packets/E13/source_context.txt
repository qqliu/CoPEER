0011 | Here is where I got up to until now:

0013 |     Base: y = 0. Then the function returns 1, as it should.
0014 |     Inductive step: The function returns the correct value for all of the numbers to n – 1.
0015 |     Induction: Let's prove that the function returns the correct value for the number n. We differentiate between 2 cases. First one is where n is even, and the second one is where n is odd.
0016 |     1) n is even:
0017 |         Function returns n + 1, as it should.
0018 |     2) n is odd:
0019 |         Function returns (2 * Increment(floor(n / 2))). floor(n / 2) is either even or odd. 
0020 | 
0021 |         If floor(n / 2) is even then we have the aforementioned case 1) in the recursive call and thus we have (floor(n / 2)+ 1) * 2 = n + 2. This is the correct result because floor(n / 2) is the florred integer and thus we have to add 2 to it.
0022 | 
0023 |         If floor(n / 2) is odd then we have case 2) again and we go into case 2) again. Then we can either go into case 1) and it will, as is explained above, yield a correct result, or we can go into case 2) again. We can go into case 2) only a finite number of times, since n is assumed to be a finite number (this wasn't stated but is implied by the limitations of computer memory). Thus after a finite amount of recursions, we will either end up in case 1) (where floor(n / 2) is even) or where floor(n / 2) is 1, which is the base of the induction. Therefore the algortihm returns the correct answer.
