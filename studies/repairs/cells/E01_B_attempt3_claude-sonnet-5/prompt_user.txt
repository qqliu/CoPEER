0004 | ---
0005 | ### Proof Methods
0006 | 
0007 | In the natural deduction style, one proves “∀ x : ℕ • P x” by proving
0008 | two statements: 
0009 | 
0010 |     Base case      :: P 0
0011 |     Inductive step :: P a ⇒ P (S a) , for a : ℕ and S successor function
0012 | 
0013 | Where, in this case,
0014 | $$P x \;\;≡\;\; ∃y \;•\; y² ≤ x < (y+1)²$$
0015 | 
0016 | In the constructive fashion, one proves “∃ y • Q x” by 
0017 | *actually finding* such a $y$ using whatever data is available.
0018 | ### Base case
0019 | 
0020 | For the [base] case the input `x` is `0`, and we need to *find*
0021 | some $y$ with $y² ≤ x < (y+1)²$. Clearly $y = 0$ works as shown
0022 | in the proof your posted.
0023 | 
0024 | ### Inductive step
0025 | 
0026 | For the [inductive] case where the input `x` is of the shape `S a`,
0027 | we need to *find* a $y$ with $y² ≤ S a < (y+1)²$, (*).
0028 | 
0029 |  1. However, we have the assumption $P a$ which gives us a $b$ with
0030 |    $b² ≤ a < (b+1)²$ --which looks really close to the goal (*).
0031 | 
0032 |  2. To reach our goal (*), let's do the simplest thing possible:
0033 |     replace $a$ with $S a$ in (1) thereby obtaining
0034 |     $b² ≤ S a < (b + 1)²$. Because of (1), and the transitivity of ≤,
0035 |     the left part is true and the whole thing reduces to:
0036 |     $$S a < (b + 1)²$$
0037 | 
0038 |  3. So if this is true, then we are done and the answer is $b$.
0039 | 
0040 |  4. If it is not true, then we must have it complement:
0041 |    $$(b + 1)² ≤ S a$$
0042 | 
0043 |     + But from (1) we also have $a < (b + 1)² = b² + 2b + 1$
0044 |       thus we obtain $S a = a + 1 < (b² + 2b + 1) + 1 ≤ b² + 4b + 2 = ((b + 1) + 1)²$
0045 |      
0046 |     + Hence, we have found that $(b + 1)² ≤ S a < ((b + 1) + 1)²$
0047 |       and so we may take the output $y$ to be $b + 1$ for our goal (*).
